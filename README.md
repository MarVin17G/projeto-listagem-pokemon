# Pokédex

Uma Pokédex interativa desenvolvida com HTML, CSS e JavaScript consumindo dados da PokéAPI.

## Funcionalidades

- Listagem dinâmica de Pokémons
- Busca por nome
- Filtro por tipo
- Dark mode
- Modal com detalhes
- Exibição de stats (HP, Attack e Defense)
- Cards com cores dinâmicas por tipo

## Tecnologias

- HTML5
- CSS3
- JavaScript
- PokéAPI
